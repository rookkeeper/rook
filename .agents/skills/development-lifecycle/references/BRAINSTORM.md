# Brainstorm

This is an advised starting set of prompts, not a required form. Every task has
different brainstorming needs, so keep only the useful sections, add anything
important, and skip this document when the work is simple or obvious.

## Problem

What problem are we solving, and what makes it worth doing now?

## Investigation

What code, docs, tests, and current behavior did we inspect?

## Options and questions

What approaches, risks, tradeoffs, or open questions emerged?

## Direction

What direction is currently preferred, and what still needs to be decided?
